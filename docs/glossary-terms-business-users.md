# Glossary of Terms - Business Users

## Purpose
This glossary explains common StorageLens terms in plain language.
It is written for business users, operations leaders, and non-technical stakeholders.

## A

### Alert
A message that tells you something needs attention, such as a failed scan or a storage threshold being reached.

### Alert Recipient
A person or team member who receives alert notifications.

### Analytics
A summarized view of scan results that helps you understand usage, trends, and storage waste.

## B

### Baseline
A starting point used to compare future storage changes.

### Batch
A group of items processed together, such as a large set of files found during a scan.

## C

### Capacity Utilization
How much of your available storage space is currently being used.

### Completed Scan
A scan that finished all planned steps and produced final results.

### Correlation ID
A tracking number used by the system to tie all scan-related activity together.

## D

### Dashboard
The main summary screen showing key storage measures and recent activity.

### Duplicate File
A file with the same content as one or more other files.

### Duplicate Group
A set of files that are identical in content.

### Duplicate Rate
The percentage of files or storage that is duplicated.

## F

### File Inventory
The catalog of discovered files and their basic details.

### File Metadata
Descriptive information about a file, such as name, path, size, and dates.

### File Path
The location of a file in your storage structure.

## H

### Hash
A unique digital fingerprint used to confirm whether files are truly identical.

### Hashing
The process of creating a fingerprint for each file so duplicates can be found accurately.

## K

### KPI (Key Performance Indicator)
A headline number used to measure storage performance, risk, or cost efficiency.

## L

### Location
A registered storage source, such as a NAS path, local path, or file share.

### Location Status
The current availability of a Storage Location, such as online, warning, or offline.

## O

### Optimization
Actions taken to reduce storage waste, improve organization, or lower storage costs.

## P

### Progress
A real-time view of how far a scan has moved through its steps.

## R

### Report
A formatted view of storage findings used for review, planning, or sharing.

### Retry
Running a failed scan step again to recover from a temporary issue.

## S

### Scan
A process that reviews a Storage Location and collects file information.

### Scan Job
One complete run of scanning activity for a selected location.

### Scan Stage
A named part of the scan process, such as scanning files, hashing, or duplicate detection.

### Scan Workflow
The full sequence of steps from starting a scan to final results.

### Storage Footprint
The total space used by your files.

### Storage Location
A folder path, share, or target source selected for analysis.

### Storage Threshold
A configured limit that triggers alerts when usage or risk goes above a chosen level.

## T

### Trend
A pattern over time, such as growing storage use or increasing duplicate waste.

## W

### Wasted Bytes
Storage space used by duplicate files that could potentially be reclaimed.

### Workflow
The ordered set of activities the system performs to produce scan results.

### Workflow Status
The current state of a scan workflow, such as running, completed, or failed.
