# Scanning Guide

## Before Starting

- Ensure location path is reachable
- Confirm proper access permissions for scan target

## Start a Scan

1. Open Storage Locations or Scan Jobs page
2. Trigger scan for the selected location
3. Track status progression in Scan Jobs

## Scan Stages

- Queued
- Scanning
- Hashing
- DetectingDuplicates
- RefreshingAnalytics
- Completed or Failed

## Troubleshooting

- If scan remains queued, verify orchestrator and downstream service health
- If scans produce no files, validate mount/path visibility from scanner runtime
