# Duplicate Analysis Guide

## Default Experience

- The Duplicates page now opens in **Interactive** mode by default.
- Use the **Original** toggle if you need the classic summary/table layout.

## What is a Duplicate Group

A duplicate group contains files that share the same hash and appear more than once.

## Key Signals

- Number of duplicate groups
- Number of duplicate files
- Potential savings (wasted bytes)
- Affected locations

## Operational Actions

- Prioritize high-waste groups first
- Engage data owners before cleanup actions
- Track duplicate reduction trends after remediation
- Use interactive exploration first to triage the highest-impact groups before switching to the classic view for broader review
