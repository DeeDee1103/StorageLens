# User Guide

## Overview

StorageLens helps operations and governance teams discover storage usage patterns, monitor scan execution, and identify duplicate data.

## Typical User Journey

1. Open the product home and navigate to the operational workspace
2. Add a storage location (it is automatically registered for global distribution tracking)
3. Start a scan
4. Monitor scan progress in Global View and Scan Jobs
5. Investigate duplicates and savings opportunities
6. Export report data when you need offline review or stakeholder sharing

After file metadata is ingested and analytics refresh runs, Global View updates location storage totals and map placement automatically.

## UI Areas

- Storage Locations
- Scan Jobs
- Product Home, Global View, and Reports
- Duplicate Analysis
